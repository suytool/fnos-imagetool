图片工具

版本 0.0.1
应用名称图片工具 (Image Tool)
版本0.0.2
开发者 / 发布者suytool
服务端口3434
运行环境飞牛 fnOS（Go 编写，单二进制运行）
技术栈Go / net/http / imaging / 思源黑体
功能特性
🧩拼图：经典九宫格 / 2~9 图模板 / 自由拼图 (7×7)
🎯格子微调：拼图格内图片支持缩放 / 拖动位置
✂️分图：1拆9 / 1拆6 / 1拆4 / 自由分图 (10×10)
💧水印：文字 + 图片水印，透明度/位置/旋转可调
🎨修改：缩放 / 旋转 / 裁剪 / 滤镜 / 格式转换
本应用为第三方应用，图片处理均在本地 NAS 完成，不会上传到任何外部服务器。
素材库与处理结果仅保存在浏览器会话中，刷新页面后自动清空。
